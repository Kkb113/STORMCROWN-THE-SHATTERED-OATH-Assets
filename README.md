# STORMCROWN: THE SHATTERED OATH

A browser-based isometric action RPG set in Aetherra, a world suspended above an endless storm.

This repository is the primary source workspace for the game. The implementation follows the supplied STORMCROWN design brief: eleven heroes, three-member parties, five regions, elemental combat, the Warden hub, and the Shattered Oath story.

## Development

The project uses modular JavaScript, WebGL2 through Three.js, and Node.js tooling. Runtime dependencies are pinned. Source, original procedural assets, tests, and deployment configuration are tracked here.

Detailed controls, testing results, asset provenance, and deployment instructions are maintained alongside the implementation.
